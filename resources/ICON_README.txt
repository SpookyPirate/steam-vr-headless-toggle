Icon File
=========

Place an icon file named "icon.ico" in this directory to use it for the executable.

If no icon is provided, the build script will use the default Python icon.

You can create an icon using:
- Online tools like favicon.io or convertio.co
- Desktop tools like GIMP or IcoFX
- Any image editing software that supports ICO format

Recommended icon size: 256x256 pixels
Format: .ico (Windows Icon)
